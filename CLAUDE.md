# Bitcoinlivet

## Product

Bitcoinlivet is a Swedish Bitcoin education and data platform focused on:

- Bitcoin
- Saving
- Purchasing power
- Inflation
- Long-term thinking

## Design

- Dark theme first
- Bitcoin orange accents
- Premium fintech/editorial design
- Calm and trustworthy

Avoid:
- Crypto casino aesthetics
- Trading-focused design
- Excessive hype

## Content

Write all user-facing content in Swedish.

Tone:
- Educational
- Trustworthy
- Optimistic
- Long-term focused

Never provide financial advice.

## Architecture

Use Vertical Slice Architecture.

Example features:

- home
- blog
- bitcoin-data
- calculator

Each feature owns:
- components
- data
- types
- helpers

## Inspiration

Use @bitcoinlivet as inspiration for:
- tone of voice
- content ideas
- visual identity

Do not copy content directly.
